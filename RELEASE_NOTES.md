# Release Notes — EventFlow MVP v1.0.0

**Дата релізу:** 28.10.2026
**Тег:** `v1.0.0`
**Статус:** стабільна версія, готова до подальшої роботи та розгортання.

## Опис релізу

Перший стабільний реліз MVP проєкту EventFlow. Зафіксовано базову архітектуру «клієнт — сервер», яка є точкою відліку для подальших ітерацій розробки.

## Нові функції

- **Бекенд (Express + TypeScript)**
  - Базовий HTTP-сервер на Express з конфігурованим портом через `PORT`.
  - Головна сторінка API (`/`) з текстовим підтвердженням роботи сервера.
  - Ендпоінт моніторингу `/health` — повертає статус `OK` та поточну мітку часу у форматі JSON.
  - Скрипти розробки та виробництва: `dev` (ts-node-dev), `build` (tsc), `start`.
- **Фронтенд (Next.js)**
  - Каркас застосунку з головною сторінкою (`pages/index.js`).

## Інфраструктура репозиторію

- Додано `.gitignore`: виключено `node_modules`, артефакти збірки (`backend/build`, `frontend/.next`), файли середовища (`.env*`), логи та системні файли.
- Додано `README.md` з описом структури та інструкціями запуску.
- Створено анотований тег `v1.0.0` для фіксації стабільної версії.

## Відомі обмеження

- Тестування ще не налаштоване (відсутні автотести в бекенді та фронтенді).
- Фронтенд не підключений до API бекенду — інтеграція запланована в наступних ітераціях.
